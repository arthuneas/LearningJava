## Sobre o Repositório: POO

Diferente de linguagens procedurais, o foco aqui é a modelagem de sistemas baseada em objetos. Este repositório documenta a implementação prática dos quatro pilares da Orientação a Objetos:

> **1. Abstração:** Isolando o essencial do que um objeto faz, escondendo detalhes desnecessários.
> **2. Encapsulamento:** Protegendo os dados internos através de modificadores de acesso (`private`, `protected`).
> **3. Herança:** Reaproveitando comportamentos e estados de classes superiores.
> **4. Polimorfismo:** Permitindo que uma mesma ação se comporte de diferentes formas dependendo do objeto.

## Roadmap de Estudos

O código está estruturado para cobrir desde a sintaxe básica até padrões de projeto mais complexos:

* **Fundamentos:** Tipos primitivos, Wrappers e estruturas de controle.
* **Classes e Objetos:** Construtores, atributos e métodos.
* **Interfaces e Classes Abstratas:** Contratos e moldes para sistemas escaláveis.
